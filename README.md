# Хаб

Хаб робочих просторів + тестовий простір «3 розмови безкоштовно».

- `index.html` — хаб: вхід власника, плитки просторів, міні-CRM, статуси.
- `test.html` — тестовий простір (карточка розмови Алекси + панель власника).
- `test.html?view=КОД` — публічна копія розбору для клієнта (без входу, чат заблоковано).
- `firestore.rules` — правила бази (проєкт `pult-hub`, акаунт «казино»).

Публікація: GitHub Pages. Конфіг Firebase публічний, доступ захищають правила.
Розбір у тесті поки шаблонний: транскрипція і ШІ підключаються через сервер.
